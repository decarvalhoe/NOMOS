# Facet vocabularies — SKOS authoring and static distribution (#643)

| Layer | Where | Owner |
|---|---|---|
| Value sets of the closed axes | `specs/facets.cue` → `specs/generated/facets-vocab.json` | CUE, single source of truth |
| SKOS authoring of the closed axes (IRIs, labels, definitions) | `core-facets.authoring.yaml` (this directory) | versioned, hand-edited |
| Open axes (activity, discipline_role, risk_tier) | `docs/regulated/domain-packs/<pack>/facet-ontology.yaml` + `*-vocabulary.yaml` | the domain packs |
| Validation | `scripts/facet_shacl_gate.py` + `specs/shacl/facet-ontology.shapes.ttl` | pySHACL, in CI |
| Distribution | `specs/generated/skos/` (`*.skos.ttl`, `*.skos.jsonld`, `index.json`, `mappings.json`) | generated by `scripts/skos_distribution.py`, committed |

## Build, check, verify

```bash
uv run --with pyshacl --with pyyaml python scripts/skos_distribution.py --root .            # rebuild the distribution
uv run --with pyshacl --with pyyaml python scripts/skos_distribution.py --root . --check    # exit 4 if the committed files are not a fresh build
uv run --with pyshacl --with pyyaml python scripts/skos_distribution.py --root . --verify   # exit 1 if a file does not round-trip to the validated graph
```

The Turtle is emitted by a canonical serializer (sorted subjects, predicates and
objects; fixed prefixes), so two builds of the same sources are byte-identical.
The authoring file refuses to build if a value exists in CUE and not in it, or
in it and not in CUE.

## Serving statically

`mappings.json` maps every IRI (scheme, collections, axes, concepts) to the
Turtle and JSON-LD file that carries it, with the media types to serve
(`text/turtle`, `application/ld+json`). Any static host can serve the directory;
content negotiation, if wanted, is a host rewrite rule, not NOMOS logic.
Skosmos or VocBench can load these files as clients; neither is required.

## Not claimed

No live SKOS service is operated or promised. No ISO 25964 conformance is
claimed (that needs licensed access and a mapping, see #580). The BFO/IOF
anchors' ontological correctness is not asserted — only that the distributed
bytes are exactly the validated graph.
