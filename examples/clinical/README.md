# Exemple Clinique

## Unités

- Source : recommandation officielle, protocole local, notice médicament, score clinique.
- Unité : critère, contre-indication, dosage, seuil, alerte, workflow d'escalade.
- Core : `decision-core`.
- Golden case : cas patient fictif validé par professionnel habilité.

## Points D'attention

- Les décisions critiques restent sous autorité humaine qualifiée.
- Le LLM peut expliquer et citer, mais ne prescrit pas.
- Les dates de recommandation et populations concernées sont obligatoires.
- Les sources confidentielles ou sous licence doivent avoir politique de citation.
