# External Assessment Pack — NOMOS

> Sprachen: [FR](README.md) · [EN](README.en.md) · **DE**

> Dieser Ordner sammelt **neutrale Inputs** fuer eine unabhaengige externe Bewertung des Zustands und Werts des NOMOS-Projekts. Er ist so geschrieben, dass eine **unparteiische** Analyse moeglich ist: ueberpruefbare Fakten, Evidenz und bekannte Luecken. Das Repository **faellt kein Werturteil** und versucht nicht, die Schlussfolgerung der Analyse zu lenken.

## Unparteilichkeitsprinzip

1. **Fakten, nicht Ueberzeugung.** Jede Aussage ist an Evidenz gebunden: Code, Tests, CI, ein generiertes Artefakt oder eine benannte Luecke — gemaess der Regel "jeder Claim verweist auf Evidenz" aus [public-claim-boundary.md](../public-claim-boundary.md).
2. **Keine Selbstbewertung.** Das Repository quantifiziert seinen eigenen Wert nicht und platziert sich auf keiner Wertskala. Bewertungs-Inputs werden als neutrale Rahmenwerke bereitgestellt, zur Anwendung durch die Analyse.
3. **Reproduzierbar.** Metriken sind datiert, an einen Commit gebunden und von Verifikationsbefehlen begleitet.
4. **Weder ueberverkauft noch unterverkauft.** Der Massstab ist die Wahrheit; der gelieferte Scope wird klar vom vorausschauenden Scope (Roadmap) unterschieden.
