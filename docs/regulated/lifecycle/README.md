# Regulated Software Lifecycle

This folder controls the software lifecycle documents for Nomos as a regulated-grade candidate.

## Document Set

| Document | Purpose | Status |
|---|---|---|
| `software-development-management-plan.md` | Lifecycle plan, organization, environments, standards, tools, reviews and evidence. | draft |
| `requirements-and-traceability-sop.md` | Requirements, source-to-test traceability and matrix conduct. | draft |
| `configuration-and-change-control-sop.md` | Baselines, branches, changes, reviews, migration and release traceability. | draft |
| `validation-master-plan.md` | Risk-based CSA/validation strategy and evidence expectations. | draft |
| `release-and-retirement-sop.md` | Release approval, rollback, retirement and record retention. | draft |

## Rule

Lifecycle records must connect:

```text
reference -> requirement -> design/configuration -> implementation -> verification -> evidence -> release decision
```
