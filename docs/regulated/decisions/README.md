# Regulated Decisions

This folder is reserved for decisions that change regulated scope, claim boundaries, control interpretation, validation strategy, or Nomos/Praxis responsibilities.

## Decision Requirements

Each decision must include:

- decision ID;
- date;
- owner;
- affected products;
- affected controls;
- rationale;
- alternatives considered;
- risk impact;
- evidence impact;
- approval status;
- follow-up issues.

Use `templates/decision-record.md` for general decisions and add regulated fields when the decision affects regulated posture.
