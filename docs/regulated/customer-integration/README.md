# Customer Integration

This folder is reserved for regulated-client integration material.

Nomos can support a client validation process, but the client remains responsible for its own regulated use, implementation context, and QMS decisions.

## Required Records

- shared responsibility matrix;
- intended-use confirmation;
- deployment boundary;
- data classification;
- electronic record/signature applicability;
- AI/RAG applicability;
- validation support checklist;
- client acceptance evidence;
- support and escalation path;
- release-impact communication record.

Use `templates/regulated/customer-integration-checklist.md` as the starting checklist.
