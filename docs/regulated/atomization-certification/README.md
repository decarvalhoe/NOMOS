# Atomization Certification

This folder is reserved for structure-aware atomization evidence.

Atomization certification is an internal evidence gate. It proves whether Nomos preserved and classified a source corpus with sufficient fidelity for the stated intended use. It is not an external legal or regulatory certification.

## Required Records

- atomization profile version;
- parser adapter inventory;
- source snapshot;
- AST coverage report;
- document structure tree report;
- atomic unit report;
- provenance envelope;
- validation report;
- open deviations and waivers;
- review coverage;
- certification decision.

Use `templates/regulated/atomization-certification-report.yaml` as the initial report format.
