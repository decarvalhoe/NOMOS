# Regulated Operations

This folder is reserved for operational controls after implementation and release.

## Minimum Procedures

- periodic review;
- audit-trail review;
- incident and nonconformity handling;
- CAPA intake and closure;
- backup and restore proof;
- retention and retrieval proof;
- access and authority review;
- dependency and vulnerability review;
- customer-impact assessment for source, model, schema, and release changes.

Use `templates/regulated/periodic-review.md` as the initial periodic review record.
