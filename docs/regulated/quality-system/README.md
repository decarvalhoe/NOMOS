# Quality System

This folder contains the draft quality-system documents required before Nomos can defend regulated-grade claims.

The documents are controlled drafts. They are not effective SOPs until owners, reviewers, approvals, training records, and evidence are established.

## Document Set

| Document | Purpose | Status |
|---|---|---|
| `quality-manual.md` | Defines QMS scope, quality policy, process map, roles, and claim boundary. | draft |
| `document-and-record-control-sop.md` | Controls creation, review, approval, versioning, retention and archival of documents/records. | draft |
| `training-and-competence-sop.md` | Defines role training, competency evidence and training effectiveness. | draft |
| `quality-risk-management-sop.md` | Defines risk assessment, control, review and risk acceptance. | draft |
| `deviation-capa-sop.md` | Defines deviations, nonconformities, root cause, corrective/preventive actions and effectiveness checks. | draft |
| `internal-audit-sop.md` | Defines internal audits, findings, grading, reports and follow-up. | draft |
| `management-review-sop.md` | Defines periodic management review inputs, outputs and decisions. | draft |

## Non-Invention Rule

If a record does not exist, write `requires_evidence`. If an owner does not exist, write `not_assigned`. If a process is not approved, write `not_effective`.
