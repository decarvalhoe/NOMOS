# Supplier Assurance Pack

This folder is reserved for client-facing supplier qualification material.

It supports client quality, validation, security, and supplier-assurance reviews. It must not claim certification unless an independent certification exists and is referenced.

## Minimum Contents

- product overview and intended-use boundaries;
- quality policy and QMS scope;
- SDLC and validation approach;
- change control and release management;
- incident, problem, and CAPA process;
- security and vulnerability management;
- data handling and subprocessor boundaries;
- business continuity and disaster recovery summary;
- audit-rights and questionnaire response material;
- release evidence bundle references.

Use `templates/regulated/supplier-assurance-pack.md` as the first controlled document.
