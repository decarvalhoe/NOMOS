## Purpose

Define access, authority checks and audit-trail expectations for Nomos controlled records and regulated operations.

## Current Status

Nomos CLI evidence exists, but a full access-control and audit-trail subsystem is not established.

## Required Controls

- role and permission matrix;
- least privilege;
- periodic access review;
- authority checks for approvals and release claims;
- immutable or append-only audit trail for controlled records;
- audit-trail review procedure;
- previous-value preservation;
- export for inspection.

## Release Impact

If a deployment uses Nomos as an electronic record approval system, this SOP is blocking until implemented and validated.
